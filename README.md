Una aplicación moderna para la gestión académica desarrollada con Spring Boot, implementando una arquitectura en capas robusta con Spring Data JPA y MySQL.

## ✨ Características Principales

- 🏗 **Arquitectura en capas** con patrón Repository
- 🔄 **CRUD completo** para entidades estudiantiles
- 💾 **Persistencia elegante** con Spring Data JPA
- ⚙️ **Configuración simplificada** gracias a Spring Boot
- 🌐 **API RESTful** para operaciones académicas

## 🛠 Stack Tecnológico

- ☕ **Java** + **Spring Boot**
- 🗃️ **Spring Data JPA**
- 🐬 **MySQL**
- 📦 **Maven**

 🎯 *Desarrollo limpio, código mantenible y mejores prácticas.*
